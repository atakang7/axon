Axon is a Go library for the part of an agent application that is easy to underestimate: **turn execution**. It coordinates a model, tools, durable working state, bounded shell/file operations, context pressure, retries, streaming, and lifecycle events.

<CardGrid>
  <Card title="Learn the model" icon="open-book">

  </Card>
  <Card title="Configure precisely" icon="setting">

  </Card>

## Axon in one picture

```text
                    your application
        UX · model choice · system prompt · policy
                         │
                         ▼
                   ┌───────────┐
user input ───────▶│   Axon    │───────▶ final assistant text
                   │  runtime  │
                   └─────┬─────┘
                         │
          ┌──────────────┼──────────────┐
          ▼              ▼              ▼
       session          model          tools
    durable state    reasoning I/O   capabilities
          │              │              │
          ├─ context     ├─ stream      ├─ files/search
          ├─ task        ├─ retries     ├─ shell/background
          └─ edits       └─ tool calls  └─ custom/MCP
```

The key boundary is simple: **the model proposes actions; the runtime owns execution and state**.
