## The Foundation for Autonomous Agents

Axon provides the hardened, production-ready primitives required to build agents like **cortex** without writing thousands of lines of boilerplate infrastructure.

<div class="code-showcase">
```go
package main

import (
    "context"
    "github.com/atakang7/axon/v2"
)

func main() {
    agent, _ := axon.New(axon.Config{
        Model:        axon.OpenAI(os.Getenv("OPENROUTER_API_KEY"), "deepseek/deepseek-v3.2"),
        SystemPrompt: "You are a careful coding agent.",
    })
    defer agent.Close()

    agent.Run(context.Background(), func() (string, bool) {
        // Your UI loop here. Axon handles the rest.
        return getInput(), true
    })
}
```
</div>

## Production-Grade Capabilities

<CardGrid stagger>
  <Card title="Infinite Context via Pruning" icon="seti:db">
    Dual-tier memory system. Uses a free recency window combined with a secondary, flash-tier LLM to aggressively park stale context and keep your primary model fast and focused.
  </Card>
  <Card title="Bulletproof Execution" icon="rocket">
    Built for real-world instability. Axon automatically handles SSE stream truncation, exponential backoffs, status-code routing, and even intercepts leaked XML markup from the model.
  </Card>
  <Card title="Asynchronous Tooling" icon="laptop">
    Not all tools return instantly. Spawn long-running watchers, servers, or database clients as background processes. Axon tracks their process groups and streams their deltas.
  </Card>
  <Card title="Strict Security Boundaries" icon="shield">
    The runtime never decides what to build. Tools are isolated via strict interfaces and flat limit caps. The agent cannot read your provider credentials or modify its own configuration.
  </Card>
</CardGrid>
