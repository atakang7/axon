## Build the product. Reuse the hard part.

Every serious agent eventually needs the same machinery: a tool-calling loop, retries, streaming, session state, context control, background processes, observability, and provider edge-case handling.

**Axon makes that layer reusable and inspectable.** Your application stays responsible for the part that actually makes it yours: the system prompt, tools, interface, policy, and product behavior.

## One runtime layer, not another agent framework

<CardGrid stagger>
  <Card title="Tool-calling loop" icon="cycle">
    Drive multi-turn model execution without rebuilding the control loop. Axon streams replies, executes tool calls, records results, and continues until the model is done.
  </Card>
  <Card title="Long-running context" icon="seti:db">
    Keep extended sessions usable with a recency window plus optional model-assisted pruning that parks stale history instead of blindly dropping it.
  </Card>
  <Card title="Real process execution" icon="laptop">
    Run foreground commands or manage long-lived background processes such as dev servers, watchers, and database clients with tracked process groups and incremental output.
  </Card>
  <Card title="Provider resilience" icon="rocket">
    Retries, SSE stream handling, status-aware failures, and malformed provider-output defenses live in the runtime instead of leaking into every agent built on top.
  </Card>
  <Card title="Sessions and events" icon="document">
    Persist conversations and consume structured runtime events to build terminal, web, or custom interfaces without coupling UI code to the execution loop.
  </Card>
  <Card title="MCP without ceremony" icon="puzzle">
    Attach MCP tool servers over stdio and expose them beside native tools through the same runtime surface.
  </Card>
</CardGrid>

## The core is intentionally boring

<div class="code-showcase">

```go
model, err := axon.OpenAI(axon.ClientConfig{
    Provider: axon.Provider{
        BaseURL: "https://openrouter.ai/api",
        Model:   "deepseek/deepseek-v3.2",
        APIKey:  os.Getenv("OPENROUTER_API_KEY"),
    },
})
if err != nil {
    log.Fatal(err)
}

agent, err := axon.New(axon.Config{
    Model:        model,
    SystemPrompt: "You are a careful coding agent.",
})
if err != nil {
    log.Fatal(err)
}
defer agent.Close()

result, err := agent.Step(ctx, "Find and fix the failing test.")
```

</div>

That is the point: **the interesting code should be your agent, not its plumbing.**
