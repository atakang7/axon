Axon is a **Go library for the execution layer of an LLM agent**. It takes a model, a system prompt, optional custom/MCP tools, and operational settings; then it drives model calls until the model stops asking for tools.

<CardGrid>
  <Card title="Deterministic turn loop">
    User input, model call, tool calls, tool results, follow-up model calls, final text. The loop is explicit and inspectable.
  </Card>
  <Card title="Bounded built-ins">
    File, search, shell, background-process, and task tools are built in with explicit time/output/context limits.
  </Card>
  <Card title="Persistent working state">
    Sessions keep the conversation, working directory, task plan, edit history, block IDs, and turn counter on disk.
  </Card>
  <Card title="Context projection">
    The historical log is preserved while old blocks can be collapsed into breadcrumbs and optionally parked by a secondary model.
  </Card>
</CardGrid>

## The shortest useful mental model

```text
Your application
  ├─ chooses/configures a Model
  ├─ supplies a system prompt
  ├─ optionally supplies custom tools / MCP servers
  └─ calls Agent.Step or Agent.Run
             │
             ▼
          Axon runtime
  session → context projection → model → tools → model → ... → final answer
             │                    │
             ├─ events            ├─ retries / streaming
             ├─ pruning           └─ OpenAI-compatible client (optional)
             └─ persistence
```
